# Validación funcional

## Objetivo
Demostrar que la aplicación funciona de extremo a extremo en el clúster.

## Validaciones realizadas
- Pods en estado Running.
- Servicios internos funcionando.
- Frontend accesible públicamente.
- Comunicación frontend → backend.
- Conexión backend → base de datos.
- Datos reales visibles en la aplicación.
- HPA activos y respondiendo.

## Evidencia funcional
- Consulta de tablas en MySQL.
- Inserción y lectura de datos.
- Verificación del estado de los servicios.
- Corrección de errores mediante logs y reinicios.

## Resultado final
La solución quedó operativa y validada para su presentación.
